# Gestures / 手势说明

本说明对应当前真人摄像头模式。先让浏览器获得摄像头权限，使至少一只完整手掌进入画面。手势需稳定一小段时间，单帧识别不会立刻召阵、定宫或收阵。具体识别效果依赖光照、画面位置与摄像头，尚需真人 QA 完整验收。

| 输入 | 作用 |
|---|---|
| `OPEN_PALM` 张掌 | 单手稳定张掌从掌心召阵；阵局展开后保持悬浮，不一直跟手移动 |
| `FIST` 握拳 | 准备术式时短握拳取消术式并保留阵；持续握拳收阵 |
| `POINT` 仅食指指向 | 扫过宫位先轻预览，稳定指向后 Focus；目标为悬浮阵面 |
| `PINCH` 拇指食指捏合 | 指向宫位后定宫；非指向状态下抓住 Hover 盘层 |
| `ROTATE` 捏合并转腕 | 拨动抓住的盘层；松开后惯性减速并吸附到最近方位 |
| `GRAB_SPACE` 双手同时捏合 | 抓取、移动和轻微倾斜整个阵局；松开后固定 |
| `SCALE` 双手张开并改变距离 | 撑大或缩小整个阵局 |
| `SPLIT` 双手张开并进一步拉远 | 与 SCALE 连续联动，使四盘沿视线方向分层；双手靠近时合拢 |
| `PUSH` 轻推掌 | 坤宫已锁定且术式 READY 时，触发土术 |
| `SWIPE_LEFT` / `SWIPE_RIGHT` 横扫 | 巽宫已锁定且 READY 时，风流沿挥动方向释放 |
| `FLICK` 新捏合保持后快速分指 | 震宫锁定后先完全松开；READY 后重新捏合、保持，再快速弹开。锁宫松手、拨盘松手和单纯移动手掌不算施术 |
| `PULL` 向身体回拉 | 坎宫已锁定且 READY 时触发水术回流 |

一只手足以完成张掌召阵 → 捏合拨盘 → 指向定宫 → 蓄势与施术 → 握拳收阵。双手操作是额外的空间控制。定宫后系统依次进入准备、对位、蓄势、READY；在 READY 前做出发动动作可能不会触发。施术后有短冷却，阵局无需反复关闭。

## 调试与个人校准

打开 `?qa=1` 并按 `D`，可查看状态、宫位、动作分数与性能。Debug 下按 `C` 可选择运行个人校准：自然张掌 1 秒、轻推 3 次、轻拉 3 次、左右短扫各 2 次、捏合松开 3 次。完成后设置保存在当前浏览器的 localStorage；它会改变个人参数。按 `R` 记录最长 10 秒的手势数值；按 `T` 开始或结束最长 60 秒的 QA 会话并下载 JSON。两种记录都不保存视频，但可能含设备和手部坐标，请审阅后再分享。

测试坤术链可打开 `?qa=kun`：页面会自动显示张掌/握拳分数、手指数、指向射线命中位置、坤宫焦点、锁定宫位、蓄势进度和 PUSH 分数，并在时间线记录失败步骤。建议依次做 20 秒张掌、10 次指坤、10 次指坤后捏合、等待 READY、10 次轻推及普通张掌移动；真实成功率需要本人摄像头测试确认。

测试巽术链可打开 `?qa=xun`：张掌召阵后指向巽宫，等 Focus，再捏合 Lock。松开并张掌，等 READY 后向左或右短扫；风带从巽宫沿画面的挥手方向释放。页面显示射线、锁宫、蓄势、120–250ms 横扫窗口、位移/速度、方向一致性、Score 和失败原因。横扫结束后稍停，再做下一次；动作尾部回弹不会反向再发动。

`swipeThreshold = 0.12` 保留原含义：摄像头归一化横向位移门槛，并非米数或 Score 门槛。Score 是多信号质量分数（0–1）；位移、速度、横向占比、方向一致性必须同时通过。只有锁定巽宫并处于蓄势/READY 的横扫可进入现有 360ms 缓冲；换宫、取消或丢手会清空巽术缓冲。真实动作幅度和成功率仍以个人摄像头测试为准。

Debug 数字键 `1`–`4` 只用于视觉模拟，不验证摄像头手势。未完成真人 QA 前，不应依据模拟演示修改默认识别阈值。

## 震术真人链 / ZHEN Flick

打开 `?qa=zhen`，用一只手完成：张掌召阵 → 指震宫并等待 Focus → PINCH 锁宫 → 完全松开 → 等待 READY → **重新 PINCH** → 保持约 260ms → 拇指／食指快速弹开。

第一次锁宫 PINCH 整个周期被消费，松开稳定至少 80ms 才能结束；READY 时已握着的旧 PINCH 不能直接蓄雷。施术只接收 READY 后的新 PINCH edge，不使用 READY 之前的 FLICK 缓冲。快速释放需下一新摄像头帧确认，最长间隔 120ms；丢手或数据间断会解除蓄势，不算松手。一次释放只能施术一次。

诊断显示 Candidate／Stable、Focus／Lock、Spell／Charge、PINCH edge、Lock Consumed、FLICK 状态、分离速度、拇指／食指相对手腕的速度、手速、Score、Fresh Sample、Cast Gate 和失败时间线。按 `R` 保存相同的数值证据。`flickThreshold=1.1` 保持不变，单位是归一化指间距离／秒，**不是 0～1 Score 的阈值**；个人校准可能覆盖默认值。PUSH、PULL、SWIPE 参数不受本阶段影响。

真人验收请分别检查：第一次锁宫松开不放雷；第二次捏合能 Armed；慢松开、拨盘松手、丢手不放雷；快速弹开只放一次。自动测试验证逻辑与合成轨迹，不替代真实摄像头成功率。
